# 如何新增一天的筆記

這個網站一天一篇筆記。不要手改 JSON，用 `scripts/add_note.py` 把下面這種固定格式的文字轉成 `notes/YYYY-MM-DD.json`，並同時更新 `notes/index.json`。

程式只使用 Python 標準函式庫，不用安裝套件。

## 執行

在儲存庫根目錄執行：

```bash
python3 scripts/add_note.py examples/2026-11-14.txt
```

從標準輸入讀取時，省略檔案路徑，或寫成 `-`：

```bash
python3 scripts/add_note.py < examples/2026-11-14.txt
```

只檢查格式、不寫入檔案：

```bash
python3 scripts/add_note.py --dry-run examples/2026-11-14.txt
```

同一天的筆記已經存在時，程式會拒絕覆寫。確定要取代才加上 `--force`：

```bash
python3 scripts/add_note.py --force examples/2026-11-14.txt
```

成功之後，把 `notes/` 裡變更過的檔案一起提交。網站是靜態檔，由 GitHub Pages 從 `main` 分支的根目錄提供，沒有建置步驟。打開某一天可以直接用網址後面的日期，例如 `#2026-11-14`。`notes/index.json` 會依日期由舊到新排序，網站預設打開最新的一天。

## 格式

- 日期獨佔一行，寫成 `日期：YYYY-MM-DD`。半形冒號 `日期:` 也可以。日期必須是真實存在的日子。
- 空行會略過。去掉前後空白後，以 `#` 開頭的行是註解，也會略過。
- 區段標題各自獨佔一行，必須是下面其中一個：【主題】、【句型】、【文法】、【單字】、【例句】、【錯誤訂正】。
- 【主題】、【句型】、【單字】一定要有。【文法】、【例句】和【錯誤訂正】可以整段省略。網頁上沒有【文法】就不顯示那一區。
- 【文法】寫在【句型】後面。每一行只以前兩個 `｜` 分成三欄：`文法點｜說明｜例句`。說明裡的 `；`、`／` 會原樣保留。例句欄再用 `；`（或 `;`）分開多個例句，每個例句是 `日文／讀音／中文`，也接受半形 `/`。讀音和中文可以省略，寫成 `日文／讀音` 或只有 `日文`。有讀音的例句會標振假名，每個例句都有發音按鈕。例句裡有漢字卻沒寫讀音時，程式會印出警告，仍然顯示、但不加注音。
- 標題一旦寫了，裡面就要有內容。同一個區段不能出現兩次，也不能是空的。
- 不在任何區段裡的文字會報錯（日期那一行除外）。
- 【句型】、【單字】、【例句】每一行都是三欄：`日文｜讀音｜中文`。
- 【錯誤訂正】每一行是三欄：`錯誤｜正確｜說明`。
- 分隔符可以用全形 `｜`，也可以用半形 `|`，同一行混用也可以。
- 【句型】、【單字】、【例句】、【錯誤訂正】每一行必須剛好三欄，欄位去掉前後空白後不可以是空的。
- 讀音欄請寫整句假名，每天的三欄格式不用改。網頁只在漢字（連續漢字算一組，也包括「々」和「〇」）上方顯示振假名，不再另列整行讀音；假名本身不標讀音。讀音仍會存進 JSON，搜尋找得到。
- 程式會把讀音對到漢字。對不齊時會在終端印出警告，並改在整句上方注音，不會中斷。若要手動指定，在 `notes/ruby-overrides.json` 用日文原文當鍵，例如 `{"お願いします": [{"t": "お"}, {"t": "願", "r": "ねが"}, {"t": "いします"}]}`。

格式不對時，程式不會寫入檔案，並盡量一次列出所有問題。跟某一行有關的錯誤會附上行號，例如「缺少或無效的日期」「缺少或空白的主題」「未知的區段標題」「欄位數量不對」「空白欄位」「這一行不在任何區段裡」「空的區段或重複的區段」。

## 完整範例

下面這則就是 2026-11-14 的筆記，內容也存在 `examples/2026-11-14.txt`。錯誤訂正第二行的「コンビ二」最後一個字是漢字「二」，正確的「コンビニ」最後一個字是片假名「ニ」，請原樣保留。

```text
日期：2026-11-14

【主題】
問路與請路人幫忙

【句型】
すみません｜すみません｜不好意思；請問一下
〇〇はどこですか（駅／トイレ／コンビニ）｜まるまるはどこですか（えき／トイレ／コンビニ）｜○○在哪裡？（車站／廁所／便利商店）
もう一度お願いします｜もういちどおねがいします｜請再說一次
ゆっくりお願いします｜ゆっくりおねがいします｜請說慢一點
ありがとうございます｜ありがとうございます｜謝謝您
すみません、道に迷いました｜すみません、みちにまよいました｜不好意思，我迷路了
すみません、写真を撮ってもらえますか｜すみません、しゃしんをとってもらえますか｜不好意思，可以請您幫我拍照嗎？
もう一枚お願いします｜もういちまいおねがいします｜請再拍一張

【單字】
まっすぐ｜まっすぐ｜直直地；一直走
右｜みぎ｜右邊
左｜ひだり｜左邊
角｜かど｜轉角；街角
信号｜しんごう｜紅綠燈；號誌
ここ｜ここ｜這裡
そこ｜そこ｜那裡（離對方較近）
あそこ｜あそこ｜那裡（離雙方都較遠）

【例句】
まっすぐ行って、信号を右です。｜まっすぐいって、しんごうをみぎです。｜一直走，在紅綠燈右轉。
あそこの角を左です。｜あそこのかどをひだりです。｜在那邊的轉角左轉。

【錯誤訂正】
すめません｜すみません｜第二個音是「み」，不是「め」。
コンビ二｜コンビニ｜最後一個音是片假名「ニ」，不是漢字「二」。
はだし｜わたし｜「はだし」是「赤腳」，「我」是「わたし」。
```
